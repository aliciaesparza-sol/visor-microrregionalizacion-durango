# Visor de Microrregionalización PVU · Durango

Visor web de la microrregionalización del Programa de Vacunación Universal (versión definitiva 02-abr-2024): institución responsable por AGEB urbana y por localidad rural, con colonias (SEPOMEX), calles con nombre, escuelas y unidades médicas (INEGI, Marco Geoestadístico 2025) y establecimientos de salud del DENUE.

Sitio estático: `index.html` + carpeta `data/`. No requiere compilación (en Cloudflare Pages: sin comando de build, directorio de salida `/`).

Fuentes: archivos de microrregionalización SSD; INEGI (Marco Geoestadístico 2019 y 2025, ITER 2020, DENUE); SEPOMEX (códigos postales y colonias).
